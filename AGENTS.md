# Qyl.Telemetry.SemanticConventions

qyl's C# and TypeScript semantic-convention bindings, generated by Weaver straight from the OpenTelemetry registries plus qyl-owned and library-native definitions; their update path is independent of upstream .NET SDK and automatic-instrumentation releases.

Push to `main` directly. Verify failing, new, changed and directly affected cases, and reuse passing results while their inputs remain unchanged. Prose-only changes need no execution check. `mise run check` is the full source gate when needed; `mise run check-full` adds coverage. CI runs the gate and reports pin freshness. Keep the actual native release checks, without adding a full-suite rerun solely for a commit or release. Regenerate affected outputs with `scripts/generate.sh` using the Weaver version pinned in `Version.props`. Releases and consumers: [`SKILL.md`](SKILL.md).

## Upstream versions

- Coverage comes from `registry/manifest.yaml` (core and GenAI pins) and `registry/vendor/` (verified library versions); audit updates against those directly. An upstream .NET SDK or agent version never establishes coverage.
- Reports keep four versions apart: the language-independent convention version, the qyl package version, the vendor-library version and the .NET SDK version.
